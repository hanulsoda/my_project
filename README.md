# 학원 학습 플레이어

서버 폴더에 있는 강의 영상을 AI로 분석해서, 학생이 **요점 정리를 보며 공부하고 원하는 설명으로 바로 이동**할 수 있게 해 주는 동영상 학습 프로그램입니다.

## 학생이 쓸 수 있는 기능

| 탭 | 기능 |
| --- | --- |
| 요점 정리 | 강의 전체 요약 + 주제별 챕터와 핵심 내용. 시간을 누르면 그 설명으로 이동합니다. 영상 아래 챕터 막대로도 이동할 수 있고, 지금 보는 챕터가 강조됩니다. 요점 정리를 만들지 않은 강의는 짝지어지는 학원 요점 정리를 그대로 보여 주고(아래 '학원 요점 정리 활용'), 그것도 없으면 로컬 AI 자동 목차를 보여 줍니다(아래 '로컬 AI 자동 목차'). |
| 페이지 | 강의 화면에서 교재 페이지가 바뀐 곳마다 작은 그림을 보여 줍니다. 지금 펴 놓은 교재와 같은 화면을 누르면 그 설명으로 이동하고, 재생 중인 화면이 강조됩니다. 요점 정리를 만든 강의는 "170쪽 · 꺼삐딴 리 지문"처럼 교재 쪽수·단원 이름표가 붙습니다. |
| 퀴즈 | 강의 내용으로 자동 생성한 4지선다 복습 문제. 답을 고르면 해설과 함께 "설명 다시 보기" 버튼이 나옵니다. 학원 요점 정리를 보여 주는 강의는 그 정리의 빈칸 문제(답 보기 → 알았어요/몰랐어요)와 어휘 뜻 고르기 문제가 나옵니다. 틀리거나 '몰랐어요'를 누른 문제는 '틀린 문제만 다시 풀기'로 다시 풀 수 있고, 모든 강의의 틀린 문제는 사이드바의 '틀린 문제 복습'에 모여 간격을 두고 다시 나옵니다: 틀리면 내일, 맞히면 3일 뒤와 7일 뒤, 세 번 이어서 맞히면 빠집니다(사이드바 숫자는 오늘 복습할 문제 수, '기다리지 않고 지금 풀기'도 있음, 학생 브라우저에 저장). 전체 풀기에서 4지선다를 끝까지 풀면 점수를 기억해 퀴즈 탭 위('지난번 4/5')와 강의 목록('퀴즈 4/5')에 보여 줍니다. |
| 질문하기 | 강의 내용에 대해 AI 튜터에게 질문합니다. 답변 속 시간을 누르면 근거 장면으로 이동합니다. "지금 보는 장면 기준으로 질문"을 켜 두면 "이 부분이 무슨 뜻이에요?" 같은 질문도 됩니다. **지금은 막아 두었습니다.** 화면에서 숨기고 서버도 질문을 받지 않습니다. 다시 켜면 비용이 마구 늘지 않도록 한 사람(인터넷은 입장 통과 하나, 학원 안은 기기 한 대)이 10분에 10번, 학원 전체가 1시간에 200번까지 질문할 수 있고, 한꺼번에는 4개까지 답합니다. 다시 쓰려면 `academy/static/watch.html`의 질문하기 버튼에서 `hidden`을 지우고, `academy/server.py` 맨 아래에서 `None` 대신 `_claude_answer()`를 넘깁니다. |
| 메모 | 지금 장면에 메모나 북마크를 남기고, 나중에 눌러서 그 장면으로 돌아갑니다. 모든 강의의 메모는 목록 화면의 '내 메모' 페이지에 강의별로 모입니다. |
| 찾기 | 선생님이 이 강의에서 그 낱말을 말한 시각을 모두(1분 안의 반복은 한 번) 그때의 챕터와 함께 보여 주고, 누르면 그 장면으로 갑니다. 받아쓰기가 한 소리 다르게 적은 말, 요점 정리·목차에만 나오는 곳도 찾습니다. 대본 글은 학생에게 보내지 않습니다. |

강의 목록의 각 줄에는 그 강의의 첫 교재 화면이 작게 나옵니다(폴더를 펼쳐 화면에 보일 때만 불러옴). 휴대폰 브라우저의 '홈 화면에 추가'로 아이콘을 만들 수 있고, 아이폰은 주소창 없이 앱처럼 열립니다(안드로이드는 https 주소일 때만 앱처럼 열리고, 지금 같은 http 주소에서는 바로가기 아이콘이 됩니다). 서버는 강의 목록 같은 글 응답을 압축해 보내고(목록 약 550KB → 100KB), 영상과 그림은 그대로 보냅니다.

그 밖에 영상을 다시 열면 **보던 위치부터 이어서 재생**되고, 강의 목록에 어디까지 봤는지 표시됩니다. 강의 목록은 맥 Finder처럼 왼쪽 사이드바에 '보관함'(이어 보기·새로 올라온 강의·내 메모·틀린 문제 복습)과 폴더(강의 수)가 있고, 폴더는 펼침 삼각형으로 세 단계까지 펼칩니다(예: 2022개정 ▸ 고1 ▸ 미래엔, 펼친 상태는 기억). 폴더를 고르면 오른쪽에 그 아래 강의들이 다음 단계(고1·고2 등)별로 나오고, 목록 보기와 그림 보기(교재 화면을 크게), 이름순과 최근 올라온 순을 고를 수 있습니다(브라우저에 기억). 키보드로도 다룹니다: 사이드바는 Finder처럼 ↑↓ 이동, → 펼치기(펼쳐져 있으면 첫 하위 폴더로), ← 접기(접혀 있으면 위 폴더로), Home/End이고, 찾기 칸에서 ↓를 누르면 첫 강의로, 목록에서는 ↑↓(그림 보기는 ←→ 옆, ↑↓ 한 줄)와 Enter로 엽니다. 선생님이 고른 **'이번 주 강의'**가 있으면 모든 학생의 사이드바 맨 위에 한마디와 함께 나오고, 선생님이 대상 학년을 붙였으면 학생이 '내 학년'을 한 번 골라 그 학년 것(과 모든 학년 것)만 봅니다. 사이드바의 **'기기 옮기기'**는 로그인 없이 6자리 코드로 메모·이어 보기·틀린 문제·퀴즈 점수·공부 기록·재생 속도를 다른 기기에 옮깁니다(서버 메모리에 10분만, 한 번 쓰면 사라짐, 받는 기기 기록과 합침, 선생님 열쇠는 옮기지 않음). 강의 줄은 그 폴더를 열거나 찾기에 걸릴 때 만들어, 휴대폰 첫 화면이 가볍습니다. 강의 줄에는 작품 이름 아래에 위치(예: '고1 · 모의고사')가, 오른쪽에 배지·퀴즈 점수·시청 막대(또는 '다 봄')가 붙습니다. 고른 폴더는 주소(`#f/폴더/하위 폴더`)에 남아 뒤로 가기와 플레이어의 '‹ 폴더' 버튼(그 강의가 든 폴더)으로 돌아옵니다. 휴대폰에서는 사이드바가 첫 화면이고 폴더를 누르면 그 폴더 화면으로 들어갑니다. 검색창은 '제목 | 선생님 말' 중 찾을 곳을 고르며, 제목은 입력하는 대로 모든 폴더에서 걸러 보여 주고(띄어쓰기·낱말 순서 무관), '요점 정리만' 스위치로 요점 정리가 있는 강의만 봅니다. 검색어·찾을 곳·스위치는 강의를 보고 돌아와도 남아 있고, 폴더 제목 아래에는 그 브라우저에서 보기 시작한 강의 수(예: '12개 봄')가 함께 나옵니다. 내 메모·틀린 문제 복습·현황도 같은 사이드바 창 안에서 열리고, 사이드바 맨 위에는 **'이번 주 공부'**(요일별로 영상을 실제로 본 시간 막대, 합계, 며칠째 이어서 공부하는지)가 나옵니다(배속과 상관없이 흐른 시간, 학생 브라우저에 두 달치 저장). 맨 위 **'이어 보기'**에는 다 보지 않은 강의가 최근에 본 순서로 5개까지, **'새로 올라온 강의'**에는 최근 14일 안에 NAS에 올라온 강의가 최신순으로 10개까지(파일 날짜 기준) 나옵니다. 찾을 곳을 **'선생님 말'**로 두고 Enter를 누르면 선생님이 그 낱말을 말한 강의를 많이 말한 순서로 찾아 주고, 시각을 누르면 그 장면부터 재생합니다(받아쓰기 대본에서 찾지만 대본 글은 학생에게 보내지 않습니다. 받아쓰기가 틀리게 적은 말은 찾지 못할 수 있습니다). 세 글자 이상 낱말은 받아쓰기가 한 음절의 자음이나 모음 하나만 다르게 적은 강의('제망매가'→'제막매가', '사잇소리'→'사이소리')도 '비슷한 말로 받아 적힌 강의'로 따로 찾아 실제로 적힌 말과 함께 보여 줍니다(마지막 음절의 받침만 다른 말은 '군주로서'처럼 조사일 때가 많아 뺍니다). 선생님 말에서 찾지 못했어도 학원 요점 정리 항목이나 목차·챕터 제목에 그 낱말이 있으면 '학원 정리·목차에 나오는 강의'로 따로 보여 줍니다(예: '전지적 작가 시점'은 학원 정리의 '시점' 항목으로 찾음, 목차에서 찾은 것은 그 시각으로 이동). 시각 옆에는 그 시각의 챕터 제목이 붙고, 같은 녹화를 여러 폴더에 넣어 둔 경우(길이와 대본 앞부분이 같음)는 한 번만 보여 주며 다른 폴더를 함께 적습니다. 플레이어 영상 아래에는 **재생 속도 버튼**(0.8~2배, 브라우저에 기억)과 챕터가 있는 강의의 **이전·다음 챕터 버튼**이 있고, 스페이스로 재생·멈춤, ←/→로 10초씩, `[`·`]`로 챕터를 이동합니다. 검색어는 30글자(띄어쓰기·기호 뺀 글자)까지 받고, 받아쓰기가 한 소리 다르게 적은 말 찾기는 10글자 이하 낱말에만 씁니다(긴 검색어로 서버가 오래 붙잡히지 않게). 검색 결과는 묶음마다 30개씩 보여 주고 '더 보기'로 이어서 봅니다(묶음마다 최대 300개). 플레이어 머리글은 왼쪽에 '‹ 폴더'(그 폴더로 돌아가기), 가운데에 작품 이름과 위치, 오른쪽에 같은 폴더의 이전·다음 강의, 북마크(지금 장면을 메모 탭에 남김), 인쇄 아이콘 버튼이 있고(영상이 끝나면 영상 위에 '다음 강의' 카드도 나옴), 영상 아래 챕터 버튼 옆에는 '3 / 14 챕터 제목'이 나오고, 챕터 막대에 마우스를 올리면 그 챕터의 교재 화면이 작게 미리 보입니다. `?`(또는 머리글의 키보드 버튼)를 누르면 단축키 표가 나오고, `B` 북마크, `N`·`P` 같은 폴더의 다음·이전 강의, `R` 구간 반복(시작점 → 끝점에서 반복 시작 → 끄기, 영상 아래 '구간 반복' 단추와 같음) 단축키가 있습니다. **인쇄**(또는 브라우저 메뉴의 인쇄)는 영상과 탭을 빼고 제목·요점 정리 탭 내용·퀴즈 문제를 찍고, 마지막 장에 정답을 따로 찍습니다(어두운 모드여도 흰 종이에 검은 글자).

## 구조

```
videos/ (강의 영상)
   │  python -m academy.analyze   ← 선생님이 서버에서 실행
   │    1. Whisper가 서버에서 말소리를 글자로 받아씀 (무료, 외부 전송 없음)
   │    2. 화면에서 페이지가 바뀌는 곳을 찾아 작은 그림으로 저장 (무료)
   │    3. (요점 정리를 만들 때) 페이지마다 화면의 교재·판서 글자를 읽음 (선택, 무료)
   │    4. Claude API가 대본과 화면 글자로 요점 정리·챕터·퀴즈·페이지 이름표 생성 (--no-guide면 건너뜀)
   ▼
data/ (영상마다 분석 결과 JSON 1개 + 페이지 그림 폴더)
   │  uvicorn academy.server:app  ← 웹 서버
   ▼
학생 브라우저 (강의 목록 → 학습 플레이어)
```

## 설치

Python 3.10 이상이 필요합니다.

리눅스·맥:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

윈도우 (PowerShell):

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

`Activate.ps1`이 "스크립트를 실행할 수 없습니다"로 막히면 명령 프롬프트(cmd)에서 `.venv\Scripts\activate`로 켜도 됩니다. 새 터미널을 열 때마다 venv를 다시 켜야 합니다.

### NVIDIA GPU 쓰기 (선택)

GPU로 받아쓰면 훨씬 빠릅니다(RTX 3060 기준 1시간 강의에 약 3분). GPU가 있으면 자동으로 쓰지만, GPU용 라이브러리(cuBLAS·cuDNN)는 따로 설치해야 합니다. 이것 없이 분석하면 `libcublas.so.12`(윈도우는 `cublas64_12.dll`) `is not found` 오류로 받아쓰기가 실패합니다.

```bash
pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
```

그리고 **분석을 실행하는 터미널에서 매번** 라이브러리 위치를 알려 줍니다.

리눅스:

```bash
export LD_LIBRARY_PATH=$(python -c 'import nvidia.cublas.lib as a, nvidia.cudnn.lib as b; print(a.__path__[0] + ":" + b.__path__[0])')
```

윈도우 (PowerShell):

```powershell
$env:PATH = (python -c "import os, nvidia.cublas, nvidia.cudnn; print(';'.join(os.path.join(m.__path__[0], 'bin') for m in (nvidia.cublas, nvidia.cudnn)))") + ";" + $env:PATH
```

GPU가 여러 개면 영상을 나눠서 동시에 받아쓸 수 있습니다. 리눅스에서는 터미널 두 개에서 각각 실행합니다.

```bash
CUDA_VISIBLE_DEVICES=0 python -m academy.analyze --part 1/2
CUDA_VISIBLE_DEVICES=1 python -m academy.analyze --part 2/2
```

GPU를 다른 프로그램(예: ollama)과 같이 쓰면 메모리가 모자라 `CUDA failed with error out of memory`로 실패할 수 있습니다. 받아쓰기에는 GPU 메모리가 약 1.5GB 필요하니, `nvidia-smi`로 남은 메모리를 확인하고 여유 있는 GPU를 `CUDA_VISIBLE_DEVICES`로 골라 다시 실행하세요. 실패한 영상만 이어서 분석합니다.

### 화면 글자 인식 (선택)

요점 정리를 만들 때 강의 화면에 띄운 교재와 판서 글자를 읽어(PaddleOCR) 함께 근거로 씁니다. 받아쓰기는 발음대로 틀리는 곳이 많은데, 화면 글자가 있으면 용어·작품명이 교재 표기대로 정확해지고 말로 하지 않은 교재 예시도 요점 정리에 들어갑니다. 페이지마다 "170쪽 · 꺼삐딴 리 지문" 같은 이름표도 붙습니다.

NVIDIA GPU가 있으면(권장) 리눅스에서 아래처럼 설치합니다. 실행 엔진은 PaddlePaddle 공식 배포처에서 받습니다.

```bash
pip install -r requirements-ocr.txt
pip install "paddlepaddle-gpu==3.3.1" -i https://www.paddlepaddle.org.cn/packages/stable/cu126/ --extra-index-url https://pypi.org/simple
```

GPU가 없으면 두 번째 줄 대신 `pip install "paddlepaddle==3.3.*"`로 설치합니다. 다만 화면 한 장에 20~40초가 걸려 1시간 강의에 20분이 넘게 걸립니다(GPU는 한 장에 0.5초, 1시간 강의에 약 2분).

- 설치하지 않으면 대본만으로 요점 정리를 만듭니다. 처음 쓸 때 글자 인식 모델을 내려받습니다.
- GPU판은 CUDA 라이브러리를 받아쓰기(Whisper)와 함께 쓰며, 설치하면서 cuBLAS 12.6·cuDNN 9.5로 맞춰집니다. 이 버전에서 받아쓰기도 정상으로 동작하는 것을 확인했습니다. 윈도우에서는 시험하지 않았습니다.
- 요점 정리를 만드는 강의만 읽고, 페이지마다 1분 간격으로 화면을 읽습니다.
- 선생님이 페이지를 넘기기 전에 판서를 지우는 경우가 많아서, 한 장면이 아니라 페이지가 떠 있는 동안 여러 번 읽어 합칩니다.

### 학원 요점 정리 활용 (선택)

학원이 이미 만든 작품별 요점 정리(이해완성·개념완성 등)가 있으면, 요점 정리를 만들 때 그 내용을 바탕으로 씁니다. 항목과 표현은 최대한 그대로 쓰고, 강의에서 설명하는 시점의 챕터에 넣어 시간을 눌러 이동할 수 있게 합니다. 요점 정리 탭 맨 위에는 작품 개요(갈래·주제 등)와 핵심 어휘가 나옵니다.

```bash
export REFERENCES_FILE=/경로/references.json
```

- 자료 파일은 작품마다 `{"title", "grade", "meta", "features", "stages", "stanzas", "persons", "fillins", "words"}`를 담은 JSON 목록입니다(`meta`는 갈래·주제 같은 이름: 값, `fillins`는 빈칸 문제 `passage`/`answer_line`, `words`는 어휘 `w`/`pos`/`def`).
- **짝짓기**: 영상 파일 이름에 작품명이 들어 있으면 그 정리를 씁니다(띄어쓰기·기호 무시, 같은 작품이 여러 학년에 있으면 폴더 이름의 학년 우선). 이름에 없으면 화면 글자에서 「작품명」으로 인용된 것을 찾습니다. 두 글자 작품명(「눈」 등)은 화면의 「」로만 짝짓습니다.
- 교재 PDF에서 자동으로 뽑은 정리에는 엉뚱한 내용·잘린 문장·중복이 섞일 수 있어서, 대본·화면 글자와 맞지 않는 항목은 Claude가 고치거나 뺍니다. **고친 내역은 `data/` JSON의 `guide.edits`에 남고 학생에게는 보내지 않으니**, 선생님이 확인하고 원본 정리를 고칠 때 쓰세요. 어떤 정리를 썼는지는 `guide.sources`에 남습니다.
- **학생 서버에도 같은 `REFERENCES_FILE`을 설정하면**, Claude 요점 정리가 없는 강의는 짝지어진 학원 정리를 요점 정리 탭에 그대로 보여 줍니다. Claude 비용이 들지 않는 대신 교재 쪽수가 없고, 뜻이 틀린 항목은 고치지 않은 채 보입니다(빈 항목·깨진 기호·줄바꿈·중복은 자동으로 정리합니다). 퀴즈는 정리의 빈칸 문제와 어휘로 만들고, **항목마다 받아쓰기 대본에서 그 내용을 말한 시간을 찾아 시간 버튼을 붙입니다**(어휘는 처음 말한 곳, 문장은 3분 구간 중 글자가 가장 많이 겹치는 곳이며 충분히 겹칠 때만). 시험에서 문장 항목의 시간은 Claude 요점 정리의 챕터와 82% 일치했습니다. 화면 글자는 정리 프린트처럼 모든 항목이 한꺼번에 보이는 장면으로 쏠려 쓰지 않습니다. 서버를 켠 뒤 처음 강의 목록을 열 때 짝짓기에 몇 초가 더 걸립니다.
- 학원 자료이므로 자료 파일과 분석 결과를 공개 저장소에 올리지 마세요.

### 로컬 AI 자동 목차 (선택)

Claude 요점 정리가 없는 강의에, 같은 컴퓨터의 [ollama](https://ollama.com) 모델로 **챕터 제목과 시작 시간만 있는 '자동 목차'**를 붙입니다. Claude 비용은 들지 않습니다. 요점 정리 탭에 챕터와 영상 아래 챕터 막대가 나오고, "자동으로 만든 목차라 틀릴 수 있다"는 안내가 붙습니다. 학원 정리가 있는 강의는 학원 정리에 챕터가 없어서 목차를 학원 정리 위에 함께 보여 주며, 밤 작업은 아무 정리도 없는 강의를 먼저 처리한 뒤 이 강의들을 처리합니다.

```bash
python -m academy.toc --until 07:00
```

- 40분 이하 강의는 대본을 통째로, **40분 넘는 강의는 20분씩 나눠** 묻고 이어 붙입니다. 긴 강의를 통째로 물으면 챕터 자리가 크게 틀렸기 때문입니다(Claude 챕터 시작점을 2분 안에서 찾은 비율이 41~62분 강의 6개에서 평균 63% → 나눠서 95%). 짧은 강의는 84%가 맞았습니다. 나눠서 만든 목차는 챕터가 2분에 하나꼴로 잘게 나뉘고, 제목에 개념 오류나 받아쓰기 오류가 섞일 수 있습니다. 받아쓰기가 작품명을 소리 하나 다르게 적은 경우('성에꽃'→'성의 꽃')는 학생에게 보낼 때 파일 이름의 작품명 철자로 바로잡습니다(저장된 목차는 그대로).
- 로컬 모델은 핵심 내용·퀴즈에서 틀린 설명을 지어내서 목차만 만듭니다.
- 이미 해 본 강의는 건너뛰므로(쓸 수 없는 답이 나온 강의는 빈 목차로 남김) 여러 번 나눠 실행해도 됩니다. `--until`이 지나면 새 강의를 시작하지 않고 코드 75로 끝나며, 모두 끝나면 0, 실패한 강의가 있으면 1로 끝납니다.
- 모델은 `TOC_MODEL`(기본 `exaone3.5:7.8b`), 주소는 `OLLAMA_URL`(기본 `http://localhost:11434`)입니다. 같은 모델을 다른 서비스와 함께 쓸 때 모델이 다시 올라가지 않도록, 문맥 길이 32768·계속 유지 설정으로 요청합니다. 다른 서비스가 바쁜 낮에는 돌리지 않는 것이 좋습니다.

## 사용 방법

### 1. 영상 준비

강의 영상을 `videos/` 폴더에 넣습니다. 하위 폴더도 됩니다(예: `videos/수학/1강.mp4`). 폴더 이름까지 강의 제목으로 표시되고, `2강`이 `10강`보다 앞에 오도록 정렬됩니다.

브라우저에서 바로 재생되는 `.mp4` `.webm` `.m4v` `.mov`만 목록에 나옵니다. `.avi` `.wmv` 같은 영상은 mp4로 바꿔 주세요.

```bash
ffmpeg -i 강의.avi -c:v libx264 -c:a aac 강의.mp4
```

### 2. Claude API 키 설정

[Claude Console](https://platform.claude.com/)에서 API 키를 만든 뒤 설정합니다. 키는 비밀번호처럼 다루세요. 채팅이나 문서에 붙여 넣지 말고, 이 프로그램 전용 키를 만들어 Console에서 사용 한도를 걸어 두면 안전합니다.

리눅스·맥: 아래 명령을 실행하고 키를 붙여 넣습니다. 입력한 키는 화면과 명령 기록에 남지 않고, 지금 터미널에서만 유지됩니다.

```bash
read -rsp "API 키: " ANTHROPIC_API_KEY && export ANTHROPIC_API_KEY
```

윈도우: 시작 메뉴에서 "계정의 환경 변수 편집"을 열고 [새로 만들기]를 누릅니다. 변수 이름은 `ANTHROPIC_API_KEY`, 값에는 키를 붙여 넣습니다. 그다음 터미널을 새로 열면 적용됩니다.

### 3. 영상 분석

```bash
python -m academy.analyze
```

- 처음 실행할 때 Whisper 음성 인식 모델(약 1.6GB)을 내려받습니다.
- **이미 분석된 영상은 건너뜁니다.** 새 영상을 올린 뒤 다시 실행하면 새 영상만 분석합니다.
- 중간에 실패한 영상이 있어도 나머지는 계속 진행합니다. 다시 실행하면 실패한 영상만 이어서 분석하고, 받아쓰기까지 끝난 영상은 받아쓰기를 다시 하지 않습니다.
- 모든 영상을 처음부터 다시 분석하려면 `python -m academy.analyze --force`.
- 받아쓰기는 서버 성능에 따라 오래 걸립니다. CPU만 있으면 영상 길이만큼 이상 걸릴 수 있고, NVIDIA GPU가 있으면 훨씬 빠릅니다(위의 "NVIDIA GPU 쓰기" 참고).
- 영상 폴더가 없거나 비어 있으면 그 사실을 알려 주고 끝납니다. `VIDEO_DIR` 설정을 확인하세요.
- 페이지 그림은 영상마다 몇 초면 만들어집니다. 예전에 분석한 영상도 다시 실행하면 받아쓰기·요점 정리는 그대로 두고 페이지만 추가합니다.

**Claude 없이 먼저 분석하기.** `python -m academy.analyze --no-guide`는 받아쓰기와 페이지만 만들고 Claude API는 쓰지 않습니다(비용 없음, API 키 필요 없음). 학생은 페이지로 원하는 설명을 찾아볼 수 있고, 강의 목록에는 "페이지"로 표시됩니다. 나중에 `--no-guide` 없이 다시 실행하면 받아쓰기를 다시 하지 않고 요점 정리·퀴즈만 추가합니다. 영상이 많으면 이렇게 먼저 전체를 돌리고, 요점 정리 비용은 한 번 확인한 뒤 붙이는 것을 권합니다.

### 4. 서버 실행

```bash
uvicorn academy.server:app --host 0.0.0.0 --port 8000
```

학생은 `http://서버주소:8000` 으로 접속합니다. 분석하는 동안에도 서버를 켜 둘 수 있고, 분석이 끝난 영상부터 요점 정리가 나타납니다.

서버는 켜질 때 모든 분석 결과를 읽어 검색용 요약을 만들고, 이 요약을 `DATA_DIR/.server-index.cache`에 저장해 둡니다. 다음에 켤 때는 바뀐 분석 결과만 다시 읽어서 빨리 뜹니다(강의 3,900개 기준 4분 → 36초). 이 파일은 지워도 되고, 지우면 다음에 켤 때 처음부터 다시 만듭니다.

선생님은 `http://서버주소:8000/status.html` 에서 현황을 볼 수 있습니다. 강의마다 학생이 받는 것(Claude 요점 정리·학원 정리·자동 목차·페이지만)의 수, 자동 목차 진행률(최근 3일 속도로 남은 날 어림, 밤 작업이 멈춰 있으면 그렇게 표시), 분석되지 않은 강의 목록이 나옵니다. 목록 화면에는 링크를 걸지 않았고, 숫자와 파일 이름만 보여 줍니다. 서버에 `LOG_DIR`(로그 폴더)를 알려 주면 그 폴더의 `backup.log`·`toc.log`·`new-videos.log` 마지막 기록(백업, 밤 작업, 새 강의 분석)도 '운영 기록'으로 함께 나오고, **이용 통계**(최근 30일 강의를 연 횟수·기기 수, 많이 연 강의 10개, 최근 4주 요일별)도 나옵니다. 이용 통계는 플레이어에서 강의를 열 때마다 `LOG_DIR/usage.log`에 시각·강의·기기 번호만 한 줄씩 남깁니다. 기기 번호는 서버만 아는 비밀값(`LOG_DIR/.usage-salt`)을 섞어 바꾼 글자라 기기 주소로 되돌릴 수 없고, 학생 이름은 남기지 않습니다. 같은 방식으로 퀴즈를 풀 때마다 강의·문제·맞음/틀림을 `LOG_DIR/quiz.log`에 남겨, 현황 화면에 **'많이 틀리는 문제'**(최근 30일, 기기마다 처음 푼 결과만, 세 기기 넘게 풀고 한 번이라도 틀린 문제를 정답률 낮은 순서로 10개)를 보여 줍니다. `USAGE_IGNORE`에 쉼표로 적은 주소(원장님 PC 등)는 세지 않습니다. 현황 화면의 **'이번 주 강의 지정'**에서 선생님 열쇠를 한 번 넣고(이 브라우저에 기억) 강의를 찾아 더한 뒤 저장하면, 모든 학생 사이드바 맨 위에 나옵니다(많아야 20개, `DATA_DIR/.teacher-picks`에 저장). **'학원 정리 고치기'**(`fixes.html`, 현황 화면에서 링크)는 학생이 요점 정리 탭에서 보는 학원 정리를 항목마다 고치기·숨기기·원래대로 합니다. 원본 정리 파일은 그대로 두고 고친 내용만 `DATA_DIR/.reference-fixes`에 저장해 학생 화면에 바로 반영하며, 너무 긴 항목(250자 넘음)과 한 단계에 내용이 몰린 구조는 '의심'으로 표시합니다. Z840에서는 선생님 열쇠를 `~/.config/academy/teacher-key`(읽기 권한은 계정만)에 두었습니다. 원장님이 Z840 터미널에서 `cat ~/.config/academy/teacher-key`로 확인해 넣습니다.

### 5. 인터넷으로 열기 (선택)

학원 사이트에 로그인한 학생만 집에서도 쓰게 하려면 [docs/인터넷-열기.md](docs/인터넷-열기.md)를 보세요. 서버는 지금처럼 Z840에서 돌고, DS918+가 https 주소와 인증서를 맡아 Z840으로 넘겨 줍니다. `ENTRY_SECRET`을 넣으면 인터넷에서 온 학생은 학원 사이트의 "강의 보기"(서명된 입장 링크)로 들어와야 하고, 들어온 뒤 12시간 동안 씁니다. 학원 내부망은 지금처럼 로그인 없이 씁니다. 인터넷에서는 현황 화면을 보는 데도 선생님 열쇠가 필요합니다. `ENTRY_SECRET`을 넣지 않은 서버는 학원 내부망 전용이라, 인터넷에서 온 요청에는 "인터넷으로는 열려 있지 않습니다"만 보여 줍니다.

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `VIDEO_DIR` | `videos` | 강의 영상 폴더 |
| `DATA_DIR` | `data` | 분석 결과 저장 폴더 |
| `ANTHROPIC_API_KEY` | (없음) | Claude API 키. 분석과 질문하기에 필요하고, 영상 시청에는 필요 없습니다. |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 요점 정리·질문 답변에 쓸 Claude 모델 |
| `WHISPER_MODEL` | `large-v3-turbo` | 음성 인식 모델. 더 정확하게는 `large-v3`(느림), 더 빠르게는 `small`(덜 정확) |
| `REFERENCES_FILE` | (없음) | 학원 요점 정리 자료 파일(JSON). 분석에서는 요점 정리의 근거로, 학생 서버에서는 요점 정리가 없는 강의에 그대로 보여 줍니다. |
| `LOG_DIR` | (없음) | 운영 로그 폴더. 있으면 선생님용 현황 페이지에 마지막 백업·밤 작업·새 강의 분석 기록과 이용 통계를 보여 줍니다. |
| `USAGE_IGNORE` | (없음) | 이용 통계에서 뺄 기기 주소, 쉼표로 구분(예: `192.168.0.6`). |
| `TEACHER_KEY_FILE` | (없음) | 선생님 열쇠가 든 파일. 있으면 현황 화면에서 '이번 주 강의'를 고르고 '학원 정리 고치기' 화면에서 학원 정리 항목을 고칠 수 있습니다(열쇠가 맞아야 저장, 한 기기에서 10번 틀리면 10분 동안 막음). 없으면 아무도 바꿀 수 없습니다. |
| `WHISPER_LANGUAGE` | `ko` | 강의 언어. 비워 두면(`WHISPER_LANGUAGE=`) 자동으로 감지합니다. |
| `ENTRY_SECRET` | (없음) | 입장 링크 비밀 키(32자 이상, 학원 사이트 PHP와 같은 값). 넣으면 인터넷에서 온 학생은 학원 사이트의 입장 링크로 들어와야 합니다. 없으면 학원 내부망 전용입니다. |
| `SITE_URL` | (없음) | 학원 사이트 주소(`https://`로 시작). 입장이 막힌 화면에 링크로 나옵니다. |
| `REQUIRE_ENTRY` | (없음) | `1`이면 `ENTRY_SECRET`이 없거나 짧을 때 서버를 시작하지 않습니다. |

## 비용 (대략적인 추정)

Claude Opus 5.5 요금(입력 100만 토큰당 $4, 출력 $20)으로 계산한 추정치입니다. 실제 비용은 강의 길이와 말의 양에 따라 다르니 [Claude Console](https://platform.claude.com/)의 사용량에서 확인하세요.

- 영상 분석: 1시간 강의 1개당 약 $0.2~0.4 (영상마다 한 번만 듭니다). 영상이 수천 개면 수백 달러가 넘을 수 있으니 `--no-guide`로 먼저 돌리는 것을 고려하세요. 화면 글자 인식을 쓰면 화면 글자를 함께 보내서 약 40% 더 듭니다.
- 질문하기: 1시간 강의 기준 질문 1개당 약 $0.02~0.15. 질문할 때마다 강의 대본 전체를 함께 보내는데, 같은 영상에 대한 질문이 5분 안에 이어지면(다른 학생의 질문이어도) 대본 부분을 캐시에서 싸게 읽어 $0.05 아래로 내려갑니다.

## 알아 둘 점

- **받아쓰기 대본은 학생에게 보여 주지 않습니다.** 받아쓰기는 소리 나는 대로 적어서 "격률"을 "경률"로 쓰는 식으로 틀린 곳이 많습니다. 그래서 대본은 서버 안에서 질문하기와 요점 정리를 만드는 데만 씁니다. 대본 전체의 흐름으로 이해하기 때문에 이런 오타가 있어도 답과 요점 정리는 대체로 정확하고, 요점 정리를 만들 때 Claude가 찾은 오타 목록은 저장된 대본에도 반영됩니다(`data/` JSON의 `guide.corrections`).
- **페이지는 교재 화면을 띄워 놓고 판서하는 화면 녹화에 맞춰져 있습니다.** 교재 쪽수 번호는 알 수 없어서 그림을 보고 고르는 방식이고, 같은 페이지를 스크롤한 위치가 따로 잡히기도 합니다. 카메라로 칠판을 찍은 영상은 화면이 계속 흔들려 페이지가 잘 나뉘지 않을 수 있습니다.
- **AI 요점 정리와 퀴즈는 틀릴 수 있습니다.** 받아쓰기에 잘못 들린 단어가 있거나 AI가 잘못 요약할 수 있으니 선생님이 한 번 검토해 주세요. `data/` 폴더의 JSON 파일을 직접 고칠 수 있습니다.
- **메모·북마크·이어보기는 학생 각자의 브라우저에 저장됩니다.** 다른 기기나 다른 브라우저에서는 보이지 않습니다.
- **학원 내부망에는 로그인이 없습니다.** 학원 안에서 주소를 아는 사람은 누구나 영상을 볼 수 있습니다. 인터넷에는 `ENTRY_SECRET`을 넣었을 때만 학원 사이트 입장 확인을 거쳐 열립니다(위 "5. 인터넷으로 열기").
- 안전 필터가 드물게 요청을 거절하면 Anthropic이 권장하는 다른 Claude 모델로 자동 재시도하도록 설정되어 있습니다.
