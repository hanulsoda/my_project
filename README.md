# 학원 학습 플레이어

서버 폴더에 있는 강의 영상을 AI로 분석해서, 학생이 **요점 정리를 보며 공부하고 원하는 설명으로 바로 이동**할 수 있게 해 주는 동영상 학습 프로그램입니다.

## 학생이 쓸 수 있는 기능

| 탭 | 기능 |
| --- | --- |
| 요점 정리 | 강의 전체 요약 + 주제별 챕터와 핵심 내용. 판서가 있는 챕터에는 칠판 사진이 함께 나오고, 사진을 누르면 그 장면으로 이동합니다. 시간을 누르면 그 설명으로 이동합니다. 영상 아래 챕터 막대로도 이동할 수 있고, 지금 보는 챕터가 강조됩니다. "인쇄" 버튼으로 요약·챕터·판서 사진·퀴즈를 종이나 PDF로 뽑을 수 있습니다(정답은 마지막 장). |
| 페이지 | 강의 화면에서 교재 페이지가 바뀐 곳마다 작은 그림을 보여 줍니다. 지금 펴 놓은 교재와 같은 화면을 누르면 그 설명으로 이동하고, 재생 중인 화면이 강조됩니다. |
| 대본 | 강의에서 한 말 전체. 검색하면 찾은 문장이 형광펜으로 표시되고, 문장을 누르면 그 장면으로 이동합니다. 재생 중인 문장을 따라 자동으로 스크롤됩니다. |
| 퀴즈 | 강의 내용으로 자동 생성한 4지선다 복습 문제. 답을 고르면 해설과 함께 "설명 다시 보기" 버튼이 나옵니다. 틀린 문제는 기억해 두었다가 "틀린 문제만 다시 풀기"로 다시 풀 수 있습니다(다음에 열어도 남아 있음). 강의 목록의 "틀린 문제 복습"에서는 모든 강의의 틀린 문제를 한 번에 모아 풀 수 있습니다(시험 전 복습용). |
| 질문하기 | 강의 내용에 대해 AI 튜터에게 질문합니다. 답변 속 시간을 누르면 근거 장면으로 이동합니다. "지금 보는 장면 기준으로 질문"을 켜 두면 "이 부분이 무슨 뜻이에요?" 같은 질문도 됩니다. |
| 메모 | 지금 장면에 메모나 북마크를 남기고, 나중에 눌러서 그 장면으로 돌아갑니다. |

그 밖에 영상을 다시 열면 **보던 위치부터 이어서 재생**되고, 강의 목록에 어디까지 봤는지 표시됩니다.

강의 목록 위 검색칸에서 **모든 강의를 한 번에 검색**할 수 있습니다. "근의 공식"처럼 찾으면 그 말이 나오는 강의와 장면이 나오고, 누르면 그 장면부터 봅니다. 대본과 요점에서 찾습니다.

영상에서 쓸 수 있는 것:

- **자막:** 받아쓴 대본으로 만든 한국어 자막. 영상 오른쪽 아래 ⋮ 메뉴 > 자막(아이폰은 말풍선 버튼)에서 켭니다. 한 번 켜면 다음 강의에서도 켜져 있습니다.
- **재생 속도:** 영상 아래 0.75~2배 버튼(⋮ 메뉴의 다른 속도도 됨). 고른 속도는 다음 강의에도 이어집니다.
- **단축키:** 스페이스 재생·멈춤, ←/→ 10초 뒤로·앞으로. 질문·메모·검색 칸에 글을 쓰는 중에는 동작하지 않습니다.

## 구조

```
videos/ (강의 영상)
   │  python -m academy.analyze   ← 선생님이 서버에서 실행
   │    1. Whisper가 서버에서 말소리를 글자로 받아씀 (무료, 외부 전송 없음)
   │    2. 화면에서 페이지가 바뀌는 곳을 찾아 작은 그림으로 저장 (무료)
   │    3. 30초마다 화면을 캡처해 거의 같은 장면은 버림 (판서 읽기용)
   │    4. Claude API가 대본과 화면 사진으로 요점 정리·챕터·퀴즈 생성 (--no-guide면 3·4는 건너뜀)
   ▼
data/ (영상마다 분석 결과 JSON 1개 + 페이지 그림 폴더 + 챕터별 판서 사진)
   │  uvicorn academy.server:app  ← 웹 서버
   ▼
학생 브라우저 (강의 목록 → 학습 플레이어)
```

## 설치

Python 3.10 이상이 필요합니다.

리눅스·맥:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

윈도우(명령 프롬프트). 관리자 권한이 아닌 일반 창에서, 내 사용자 폴더처럼 시스템 폴더가 아닌 곳에서 실행하세요.

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

새 창을 열 때마다 `.venv\Scripts\activate`(리눅스·맥은 `source .venv/bin/activate`)로 다시 켜야 합니다.

### NVIDIA GPU 쓰기 (선택)

GPU로 받아쓰면 훨씬 빠릅니다(RTX 3060 기준 1시간 강의에 약 3분). `nvidia-smi`를 실행해 오른쪽 위 `CUDA Version`이 12 이상이면 쓸 수 있습니다. GPU용 라이브러리(cuBLAS·cuDNN)를 한 번 설치하고, **분석을 실행하는 창에서 매번** 라이브러리 위치를 알려 줍니다.

```bash
pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
```

리눅스:

```bash
export LD_LIBRARY_PATH=$(python -c 'import os, nvidia.cublas, nvidia.cudnn; print(os.path.join(list(nvidia.cublas.__path__)[0], "lib") + ":" + os.path.join(list(nvidia.cudnn.__path__)[0], "lib"))')
```

윈도우(명령 프롬프트):

```bat
for /f "usebackq delims=" %p in (`python -c "import os, nvidia.cublas, nvidia.cudnn; print(os.path.join(list(nvidia.cublas.__path__)[0], 'bin') + ';' + os.path.join(list(nvidia.cudnn.__path__)[0], 'bin'))"`) do set "PATH=%p;%PATH%"
```

NVIDIA 그래픽카드가 있는데 위 명령을 빠뜨리면 `Library libcublas.so.12 is not found or cannot be loaded`(윈도우는 `cublas64_12.dll`) 같은 오류로 모든 영상이 실패합니다. 그때는 위 명령을 실행한 뒤 다시 분석하세요. NVIDIA 그래픽카드가 없는 컴퓨터는 자동으로 CPU를 씁니다.

GPU가 여러 개면 영상을 나눠서 동시에 받아쓸 수 있습니다. 리눅스에서는 터미널 두 개에서 각각 실행합니다.

```bash
CUDA_VISIBLE_DEVICES=0 python -m academy.analyze --part 1/2
CUDA_VISIBLE_DEVICES=1 python -m academy.analyze --part 2/2
```

GPU를 다른 프로그램(예: ollama)과 같이 쓰면 메모리가 모자라 `CUDA failed with error out of memory`로 실패할 수 있습니다. 받아쓰기에는 GPU 메모리가 약 1.5GB 필요하니, `nvidia-smi`로 남은 메모리를 확인하고 여유 있는 GPU를 `CUDA_VISIBLE_DEVICES`로 골라 다시 실행하세요. 실패한 영상만 이어서 분석합니다.

## 사용 방법

### 1. 영상 준비

강의 영상을 `videos/` 폴더에 넣습니다. 하위 폴더도 됩니다(예: `videos/수학/1강.mp4`). 폴더 이름까지 강의 제목으로 표시되고, `2강`이 `10강`보다 앞에 오도록 정렬됩니다. 서버를 켜 둔 채 새로 넣은 영상은 5분 안에 목록에 나타납니다.

브라우저에서 바로 재생되는 `.mp4` `.webm` `.m4v` `.mov`만 목록에 나옵니다. `.avi` `.wmv` 같은 영상은 mp4로 바꿔 주세요.

```bash
ffmpeg -i 강의.avi -c:v libx264 -c:a aac 강의.mp4
```

### 2. Claude API 키 설정

[Claude Console](https://platform.claude.com/)에서 API 키를 만든 뒤 설정합니다. 키는 비밀번호처럼 다루세요. 채팅이나 문서에 붙여 넣지 말고, 이 프로그램 전용 키를 만들어 Console에서 사용 한도를 걸어 두면 안전합니다.

리눅스·맥: 아래 명령을 실행하고 키를 붙여 넣습니다. 입력한 키는 화면과 명령 기록에 남지 않고, 지금 터미널에서만 유지됩니다.

```bash
read -rsp "API 키: " ANTHROPIC_API_KEY && export ANTHROPIC_API_KEY
```

윈도우: 시작 메뉴에서 "계정의 환경 변수 편집"을 열고 [새로 만들기]를 누릅니다. 변수 이름은 `ANTHROPIC_API_KEY`, 값에는 키를 붙여 넣습니다. 그다음 터미널을 새로 열면 적용됩니다.

### 3. 영상 분석

```bash
python -m academy.analyze
```

- 영상을 하나도 못 찾으면 찾아본 폴더 경로를 알려 주고 멈춥니다. 다른 폴더를 쓰려면 `VIDEO_DIR`을 설정하세요(아래 "설정" 참고).
- 처음 실행할 때 Whisper 음성 인식 모델(약 1.6GB)을 내려받습니다.
- **이미 분석된 영상은 건너뜁니다.** 새 영상을 올린 뒤 다시 실행하면 새 영상만 분석합니다.
- 중간에 실패한 영상이 있어도 나머지는 계속 진행합니다. 다시 실행하면 실패한 영상만 이어서 분석하고, 받아쓰기까지 끝난 영상은 받아쓰기를 다시 하지 않습니다.
- 모든 영상을 처음부터 다시 분석하려면 `python -m academy.analyze --force`.
- 판서 사진 기능 전에 분석한 영상에는 사진이 없습니다. 사진을 넣으려면 `--force`로 다시 분석하세요(받아쓰기부터 다시 하므로 오래 걸립니다). 영상 하나만 다시 하려면 `data/`의 그 영상 JSON 파일에서 `"guide"` 값을 `null`로 바꾸고 분석을 실행하면, 받아쓰기는 건너뛰고 요점 정리와 사진만 다시 만듭니다.
- 판서 사진이 쓸 만한지 먼저 보려면 `python -m academy.frames 1강.mp4`를 실행하세요. 분석 때 Claude에 보낼 사진이 `판서-미리보기/1강/` 폴더에 `01-30.jpg`처럼 시간 이름으로 저장됩니다(`videos/수학/1강.mp4`처럼 폴더 안의 영상은 `판서-미리보기/수학-1강/`). API 비용이 들지 않고 받아쓰기도 하지 않습니다.
- 받아쓰기는 서버 성능에 따라 오래 걸립니다. CPU만 있으면 영상 길이만큼 이상 걸릴 수 있고, NVIDIA GPU가 있으면 훨씬 빠릅니다(위의 "NVIDIA GPU 쓰기" 참고).
- 페이지 그림은 영상마다 몇 초면 만들어집니다. 예전에 분석한 영상도 다시 실행하면 받아쓰기·요점 정리는 그대로 두고 페이지만 추가합니다.

**Claude 없이 먼저 분석하기.** `python -m academy.analyze --no-guide`는 받아쓰기와 페이지만 만들고 Claude API는 쓰지 않습니다(비용 없음, API 키 필요 없음). 학생은 페이지·대본으로 원하는 설명을 찾아볼 수 있고, 강의 목록에는 "대본·페이지"로 표시됩니다. 나중에 `--no-guide` 없이 다시 실행하면 받아쓰기를 다시 하지 않고 요점 정리·퀴즈와 판서 사진만 추가합니다. 영상이 많으면 이렇게 먼저 전체를 돌리고, 요점 정리 비용은 한 번 확인한 뒤 붙이는 것을 권합니다.

### 4. 서버 실행

```bash
python -m uvicorn academy.server:app --host 0.0.0.0 --port 8000
```

학생은 `http://서버주소:8000` 으로 접속합니다. 분석하는 동안에도 서버를 켜 둘 수 있고, 분석이 끝난 영상부터 요점 정리가 나타납니다.

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
| --- | --- | --- |
| `VIDEO_DIR` | `videos` | 강의 영상 폴더 |
| `DATA_DIR` | `data` | 분석 결과 저장 폴더 |
| `ANTHROPIC_API_KEY` | (없음) | Claude API 키. 분석과 질문하기에 필요하고, 영상 시청에는 필요 없습니다. |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 요점 정리·질문 답변에 쓸 Claude 모델 |
| `WHISPER_MODEL` | `large-v3-turbo` | 음성 인식 모델. 더 정확하게는 `large-v3`(느림), 더 빠르게는 `small`(덜 정확) |
| `WHISPER_LANGUAGE` | `ko` | 강의 언어. 비워 두면(`WHISPER_LANGUAGE=`) 자동으로 감지합니다. |
| `ENTRY_SECRET` | (없음) | 입장 링크 비밀 키(32자 이상). 넣으면 학원 사이트의 입장 링크로 들어온 학생만 쓸 수 있습니다. 학원 사이트 PHP와 같은 값 |
| `REQUIRE_ENTRY` | (없음) | `1`이면 `ENTRY_SECRET`이 없거나 짧을 때 서버를 시작하지 않습니다. 실수로 열어 두는 것을 막습니다. |
| `SITE_URL` | (없음) | 학원 사이트 주소(`https://`로 시작). 입장이 막힌 화면에 링크로 나옵니다. |

## 비용 (대략적인 추정)

Claude Opus 5.5 요금(입력 100만 토큰당 $4, 출력 $20)으로 계산한 추정치입니다. 실제 비용은 강의 길이와 말의 양에 따라 다르니 [Claude Console](https://platform.claude.com/)의 사용량에서 확인하세요.

- 영상 분석: 1시간 강의 1개당 약 $0.2~0.4 (영상마다 한 번만 듭니다). 영상이 수천 개면 수백 달러가 넘을 수 있으니 `--no-guide`로 먼저 돌리는 것을 고려하세요.
- 판서 사진: 화면 사진을 함께 보내서 1시간 강의당 약 $0.2~0.3 추가. 화면이 거의 바뀌지 않는 강의는 사진이 적어 더 쌉니다.
- 질문하기: 1시간 강의 기준 질문 1개당 약 $0.02~0.15. 질문할 때마다 강의 대본 전체를 함께 보내는데, 같은 영상에 대한 질문이 5분 안에 이어지면(다른 학생의 질문이어도) 대본 부분을 캐시에서 싸게 읽어 $0.05 아래로 내려갑니다.

## 알아 둘 점

- **받아쓰기 오타는 대본에도 자동으로 고쳐집니다.** 받아쓰기는 소리 나는 대로 적어서 "격률"을 "경률"로 쓰는 식으로 틀리곤 합니다. 요점 정리를 만들 때 Claude가 이런 오타 목록을 함께 찾아 대본에 반영하므로 대본 검색과 질문하기에도 바른 용어가 쓰입니다. 바꾼 목록은 `data/` JSON의 `guide.corrections`에 남습니다.
- **페이지는 교재 화면을 띄워 놓고 판서하는 화면 녹화에 맞춰져 있습니다.** 교재 쪽수 번호는 알 수 없어서 그림을 보고 고르는 방식이고, 같은 페이지를 스크롤한 위치가 따로 잡히기도 합니다. 카메라로 칠판을 찍은 영상은 화면이 계속 흔들려 페이지가 잘 나뉘지 않을 수 있습니다.
- **AI 요점 정리와 퀴즈는 틀릴 수 있습니다.** 받아쓰기에 잘못 들린 단어가 있거나 AI가 잘못 요약할 수 있으니 선생님이 한 번 검토해 주세요. `data/` 폴더의 JSON 파일을 직접 고칠 수 있습니다.
- **메모·북마크·이어보기는 학생 각자의 브라우저에 저장됩니다.** 다른 기기나 다른 브라우저에서는 보이지 않습니다.
- **입장 확인은 비밀 키를 넣었을 때만 켜집니다.** 학습 플레이어에는 따로 로그인 화면이 없고, `ENTRY_SECRET`을 설정하면 학원 사이트에 로그인한 학생이 "강의 보기" 링크로 들어왔을 때만 쓸 수 있습니다(들어온 뒤 12시간). 위 "4. 서버 실행"처럼 비밀 키 없이 켜면 주소를 아는 사람은 누구나 영상을 보고 질문할 수 있고, 질문할 때마다 API 비용이 듭니다. 학원 내부망 밖에 공개하려면 [docs/시놀로지-설치.md](docs/시놀로지-설치.md)대로 입장 확인을 켜세요.
- **질문하기는 횟수를 제한합니다.** API 비용이 한 사람이나 프로그램 때문에 불어나지 않도록, 학생 한 명(입장 확인을 끄면 컴퓨터 한 대)이 10분에 10번, 전체가 1시간에 200번까지 질문할 수 있고, 한꺼번에는 4개까지 답합니다. 넘으면 학생 화면에 잠시 뒤 다시 하라고 나옵니다.
- **학원 사이트 안에 틀(iframe)로 넣을 수 없습니다.** 다른 사이트가 플레이어를 몰래 띄우지 못하게 막아 두었습니다. "강의 보기" 링크로 새 화면에서 엽니다.
