# 학습 플레이어를 인터넷으로 열기 (선택)

학원 사이트에 로그인한 학생만 집에서도 학습 플레이어를 쓸 수 있게 하는 방법입니다. 플레이어 서버는 지금처럼 Z840에서 돌고, DS918+는 인터넷 주소(https)와 인증서만 맡아 Z840으로 넘겨 줍니다. 학원 안에서 `http://Z840주소:8000`으로 쓰던 방식은 그대로이고 로그인도 필요 없습니다.

```
집의 학생 ── https://study.학원도메인 ── 공유기(80·443) ── DS918+ (인증서·역방향 프록시) ── http://Z840주소:8000
학원 PC  ───────────────────────────────────────────────────────────────── http://Z840주소:8000 (지금처럼)
```

- 인터넷에서 온 학생은 학원 사이트의 "강의 보기"로 들어와야 하고, 들어온 뒤 12시간 동안 씁니다. 12시간이 지나면 화면이 "학원 사이트에 로그인한 뒤 들어와 주세요"로 바뀝니다.
- 메모·이어 보기 같은 학생 기록은 기기마다 따로입니다. 집과 학원 사이에서는 사이드바의 '기기 옮기기'로 옮깁니다. 집에서 만든 코드를 학원에서 받을 수 있습니다.
- 선생님 화면(`status.html`, `fixes.html`)도 인터넷에서는 "강의 보기"로 들어온 뒤에 열리고, 바꾸려면 지금처럼 선생님 열쇠가 필요합니다. 현황(이용 통계·운영 기록)은 인터넷에서는 **보기만 해도** 선생님 열쇠가 있어야 합니다. 현황 화면의 '이번 주 강의 지정'에 열쇠를 넣으면 그 브라우저에서는 계속 보입니다. 학원 안에서는 지금처럼 열쇠 없이 봅니다.

**준비물:** Z840 터미널, DS918+ 관리자 계정, 공유기 관리 화면, 학원 도메인 관리(DNS) 화면, 학원 사이트 파일을 고칠 권한

**주의:** 2단계에서 공유기 설정을 바꾸는 순간 DS718+의 기존 영상 주소는 바깥에서 열리지 않습니다. 2단계와 3단계(학원 사이트 버튼 교체)는 같은 날 이어서 하세요.

## 1. Z840: 비밀 키를 만들고 서버 설정 더하기

1. 입장 링크에 쓸 비밀 키를 만듭니다. 플레이어(여기)와 학원 사이트(3단계) 두 곳에 **같은 값**을 넣습니다.
   ```bash
   python3 -c "import secrets; print(secrets.token_hex(32))" > ~/.config/academy/entry-secret
   chmod 600 ~/.config/academy/entry-secret
   cat ~/.config/academy/entry-secret   # 64자. 3단계에서 학원 사이트에 넣을 값
   ```
   남에게 보여 주거나 GitHub에 올리지 마세요.
2. 플레이어 서버를 켜는 명령에 환경 변수 두 개와 `--proxy-headers` 설정을 더합니다. 지금 쓰는 `REFERENCES_FILE`, `LOG_DIR`, `TEACHER_KEY_FILE` 같은 설정은 그대로 둡니다.
   ```bash
   ENTRY_SECRET=$(cat ~/.config/academy/entry-secret) SITE_URL=https://학원사이트주소 \
   uvicorn academy.server:app --host 0.0.0.0 --port 8000 --proxy-headers --forwarded-allow-ips DS918주소
   ```
   - `SITE_URL`은 `https://`로 시작해야 합니다. 막힘 화면에 "학원 사이트로 가기" 링크로 나옵니다.
   - `--forwarded-allow-ips`에는 DS918+의 내부 주소(예: `192.168.0.10`)를 넣습니다. 이게 없으면 인터넷에서 온 학생이 모두 DS918+ 한 대로 보입니다. 그러면 현황 화면의 이용 통계 기기 수가 맞지 않고, 선생님 열쇠를 10번 틀렸을 때의 잠금도 모두에게 걸립니다.
3. **확인:** 학원 PC 브라우저에서 `http://Z840주소:8000`을 엽니다. 지금처럼 강의 목록이 나오면 정상입니다.

## 2. DS918+: 인터넷 주소 연결

1. **DNS:** 도메인 관리 화면에서 `study` 레코드를 추가합니다. 값은 지금 DS718+ 영상 주소가 가리키는 것과 같은 학원 인터넷 주소(공인 IP)입니다.
2. **공유기:** 포트 포워딩에서 **80, 443번**이 DS718+ 대신 **DS918+의 내부 주소**로 가도록 바꿉니다. Z840의 8000번은 포워딩하지 않습니다.
3. **인증서:** 제어판 > **보안** > **인증서** > **추가** > 새 인증서 추가 > **Let's Encrypt에서 인증서 받기**
   - 도메인 이름 `study.학원도메인`, 이메일 입력 > 완료
   - 80번 포트가 DS918+로 열려 있어야 발급되고, 90일마다 자동으로 갱신됩니다.
4. **역방향 프록시:** 제어판 > **로그인 포털** > **고급** > **역방향 프록시** > **생성**
   - 소스: 프로토콜 `HTTPS`, 호스트 이름 `study.학원도메인`, 포트 `443`, **HSTS 사용** 체크
   - 대상: 프로토콜 `HTTP`, 호스트 이름 `Z840주소`(예: `192.168.0.20`), 포트 `8000`
   - **사용자 지정 머리글** > 생성으로 두 줄을 넣습니다. **둘 다 꼭 넣으세요.** 플레이어는 이 머리글로 인터넷에서 온 요청인지 알아봅니다.
     - 이름 `X-Forwarded-Proto`, 값 `$scheme`
     - 이름 `X-Forwarded-For`, 값 `$proxy_add_x_forwarded_for`
5. 제어판 > 보안 > 인증서 > **설정**에서 `study.학원도메인` 항목에 3번의 인증서를 고릅니다.
6. **확인:** 휴대폰의 와이파이를 끄고(데이터로) `https://study.학원도메인`을 엽니다. 자물쇠 표시와 함께 "학원 사이트에 로그인한 뒤 들어와 주세요"가 나오면 정상입니다.
   - **강의 목록이 그냥 보이면 바로 멈추고** 공유기의 443번 포워딩을 잠시 끄세요. 입장 확인이 켜지지 않은 것입니다. 1단계 2번의 `ENTRY_SECRET`과 4번의 머리글 두 줄을 확인합니다.

## 3. 학원 사이트에 "강의 보기" 버튼 달기

입장 링크는 5분만 유효합니다. 학생이 화면을 오래 열어 둔 뒤 눌러도 되도록, 버튼은 **누르는 순간 새 링크를 만드는 페이지**로 연결합니다.

1. 저장소의 `deploy/study_player_link.php`를 학원 사이트에 올립니다.
2. 비밀 키는 **웹 주소로 열리지 않는 폴더**에 둡니다. 웹 폴더(`www`나 `public_html`)의 바로 위입니다. 그곳에 아래 한 줄로 `study_secret.php`를 만듭니다.
   ```php
   <?php return '1단계의 64자 값';
   ```
   웹 폴더 안에 두면 사이트 백업 파일이나 서버 설정 실수로 키가 샐 수 있습니다. 호스팅에서 웹 폴더 바깥에 파일을 만들 수 없으면 웹 폴더 안에 두고, 3번 코드의 `'/../study_secret.php'`를 `'/study_secret.php'`로 바꿉니다(`.php` 파일이라 주소로 열어도 키는 보이지 않습니다).
3. 1번 파일과 같은 폴더에 아래 내용으로 `study_go.php`를 만듭니다.
   ```php
   <?php
   // "강의 보기" 버튼이 오는 페이지. 누른 순간의 새 입장 링크로 보냅니다.
   session_start();
   // ↓ 다른 학생 전용 페이지와 똑같은 로그인 확인으로 바꾸세요.
   //   바꾸지 않으면 아무도 들어갈 수 없습니다(실수해도 열리지 않게 한 기본값).
   if (empty($_SESSION['여기에_로그인_확인_키'])) {
       http_response_code(403);
       exit('로그인이 필요합니다.');
   }
   require_once __DIR__ . '/study_player_link.php';
   // 바로 위 2번의 파일을 웹 폴더의 바로 위에서 찾습니다. study_go.php를 어느 폴더에 두어도 같습니다.
   $secret_file = $_SERVER['DOCUMENT_ROOT'] . '/../study_secret.php';
   if (!is_file($secret_file)) {
       http_response_code(500);
       exit('study_secret.php를 찾지 못했습니다. 인터넷으로 열기 안내 3단계 2번을 확인하세요.');
   }
   header('Location: ' . study_player_link('https://study.학원도메인', require $secret_file));
   ```
4. 로그인한 학생이 보는 화면의 기존 DS718+ 영상 링크를 `<a href="study_go.php">강의 보기</a>`로 바꿉니다. 폴더가 다르면 경로를 맞추세요.
5. **확인:** 학생 계정으로 로그인 > 강의 보기 > 강의 목록이 나오면 정상입니다. 로그아웃한 상태에서 `study_go.php`를 직접 열면 "로그인이 필요합니다."가 나와야 합니다.

## 질문하기를 다시 켤 때

지금은 질문하기를 꺼 두었습니다(README의 질문하기 줄 참고). 다시 켜면 인터넷 학생도 질문할 수 있고 질문마다 API 비용이 듭니다.
- 한 사람(인터넷은 입장 통과 하나, 학원 안은 기기 한 대)은 10분에 10번, 학원 전체는 1시간에 200번까지 질문할 수 있습니다. 한꺼번에는 4개까지 답합니다.
- [Claude Console](https://platform.claude.com/)에서 **Spend limits(사용 한도)**로 한 달 한도를 정해 두세요(Settings > Limits나 Billing 화면). 한도에 닿으면 다음 달 1일 오전 9시(한국 시간)까지 질문하기와 분석이 멈추고, 영상 시청은 계속됩니다.

## 막힐 때

| 증상 | 확인할 것 |
| --- | --- |
| 인터넷 학생에게 "인터넷으로는 열려 있지 않습니다"가 나옴 | 서버에 `ENTRY_SECRET`이 들어가지 않았습니다. 1단계 1번의 비밀 키 파일이 있는지(`cat ~/.config/academy/entry-secret`), 2번의 실행 명령에 `ENTRY_SECRET=...`을 넣었는지 |
| 휴대폰 데이터로 열었는데 강의 목록이 그냥 보임 | 입장 확인이 꺼져 있습니다. 1단계 2번의 `ENTRY_SECRET`, 2단계 4번의 사용자 지정 머리글 두 줄 |
| 모든 학생이 "로그인한 뒤 들어와 주세요"에서 막힘 | 1단계와 3단계의 비밀 키가 같은지, Z840과 웹호스팅 서버의 시계가 맞는지(5분 넘게 차이 나면 링크가 바로 만료됨) |
| `502 Bad Gateway` 같은 오류 화면 | Z840 플레이어가 켜져 있는지, 역방향 프록시 대상 주소·포트(`Z840주소`·`8000`), Z840 방화벽이 DS918+에서 8000번을 막지 않는지 |
| 서버가 켜지자마자 꺼짐 | 터미널의 메시지. `SITE_URL`은 `https://`로 시작해야 합니다 |
| 현황 화면의 이용 통계에서 인터넷 학생이 모두 한 기기로 셈 | 1단계 2번의 `--proxy-headers --forwarded-allow-ips DS918주소` |
| 학원 안에서 `https://study.학원도메인`만 안 열림 | 공유기의 NAT 루프백 기능. 학원 안에서는 `http://Z840주소:8000`을 그대로 써도 됩니다 |
| 인증서 발급 실패 | 공유기 80번이 DS918+로 가는지 |
