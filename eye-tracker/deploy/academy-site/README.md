# 다힘 사이트에서 읽기 시선 기록으로 들어가기 (학원 사이트 쪽 설치)

이 폴더의 파일은 **다힘(학원) 사이트 서버**에 올립니다. 읽기 시선 기록 서버(reading.dahim.kr)에는 올리지 않습니다.
원장님·선생님·학생은 이미 다힘 사이트에 로그인해 있으므로, 따로 로그인하지 않고 메뉴 버튼 한 번으로 들어옵니다.

- `reading_go.php` : 버튼이 가리키는 페이지. 로그인 세션을 보고 5분짜리 한 번용 입장 토큰을 만들어 `https://reading.dahim.kr/sso`로 보냅니다.
- `reading_sso_lib.php` : 토큰을 만드는 함수(`reading_sso_token`, `reading_go_decide`). `reading_go.php`와 같은 폴더에 둡니다.

PHP 8.0 이상이 필요합니다(`match`, `catch (Throwable)`). 전체 흐름과 토큰 약속은 `eye-tracker/docs/sso.md`를 보세요.

## 1. 누가 어떤 역할로 들어오나 (세션 값만 봅니다)
| 다힘 세션 | 읽기 시선 기록에서 |
|---|---|
| `admin_logged_in` 이고 `admin_teacher_id`가 0 | 원장(모든 아이를 봄), 토큰 `role=director`, `uid=admin` |
| `admin_logged_in` 이고 `admin_teacher_id`가 1 이상 | 선생님(자기 아이만), `role=teacher`, `uid=선생님 번호` |
| `student_logged_in === true`, `student_id` "0123" | 학생(자기 측정만, 점수는 안 보임), `role=student`, `uid=sid=학생 번호` |

- 역할과 번호는 **세션에서만** 읽습니다. 주소창 값(`?role=`, `?uid=` 같은 것)은 전혀 쓰지 않습니다.
- 예외 하나: 선생님·원장이 학생 화면의 "측정" 버튼으로 오면 `?student=0123`을 붙입니다. 이 값은 4자리 숫자인지 확인하고,
  다힘의 `drs_scope()` / `drs_ok($scope, $id)`가 있으면 "맡은 반 학생인지"를 확인합니다(원장은 `drs_scope()`가 `null`이라 제한 없음).
  두 함수가 없으면(파일 경로가 틀린 경우 등) **선생님의 학생 지정은 막힙니다**(안전한 쪽). `function_exists`로 확인하므로 함수가 없어도 페이지가 깨지지는 않습니다.
- 로그인이 안 되어 있으면 다힘 로그인 주소(`ACADEMY_LOGIN_URL`)로 보냅니다.
- 토큰에는 이름 등 개인정보가 없습니다. 역할, 번호, 만료 시각, 한 번용 난수뿐입니다.

## 2. 설치
1. `reading_go.php`, `reading_sso_lib.php`를 다힘 사이트의 웹 폴더(예: 사이트 맨 위)에 올립니다.
2. `reading_go.php` 맨 위 설정을 서버에 맞게 고칩니다.
   - `ACADEMY_LOGIN_URL` : 다힘 로그인 페이지 주소.
   - `READING_SCOPE_LIB` : `drs_scope()`가 들어 있는 파일(다힘 코드에서는 `admin/lib/drill_scope.php`). 경로는 `reading_go.php` 위치 기준입니다.
   - `READING_SECRET_FILE` : 아래 3번의 비밀값 파일 위치(웹 루트 **밖**).
3. 비밀값(공유 비밀) 넣기 — 둘 중 하나:
   - 환경변수 `DAHIM_READING_SECRET` (php-fpm 풀 설정의 `env[DAHIM_READING_SECRET] = ...` 등), 또는
   - 웹 루트 밖의 PHP 파일, 예: `/home/dahim/private/reading_secret.php`
     ```php
     <?php return '여기에-비밀값';
     ```
     `chmod 640`, 웹 서버 사용자만 읽을 수 있게. 이 파일은 **절대 git에 올리지 않습니다.**
   - 값은 읽기 시선 기록 서버 `.env`의 `SSO_SECRET`과 **똑같아야** 합니다. 32자 이상. 만들기: `openssl rand -hex 32`
   - 앞뒤 공백·줄바꿈은 양쪽 모두 자동으로 지웁니다. 비밀값은 채팅·메일·로그에 남기지 마세요.

## 3. 메뉴 링크 달기
- 원장/강사 메뉴: **"읽기 시선 기록"** → `/reading_go.php`
- 학생 메뉴: **"읽기 측정"** → `/reading_go.php` (같은 주소. 학생 세션이면 학생으로 들어갑니다)
- 선생님의 학생 화면: **"측정"** 버튼 → `/reading_go.php?student=<4자리 학생 번호>` (예: `?student=0123`)
  - 그 학생이 아직 등록되어 있지 않으면, 읽기 시선 기록에서 "측정 대상으로 등록" 칸이 학생 번호가 채워진 채로 나옵니다(이름은 저장하지 않음).
- 새 창으로 열어도 되고 같은 창도 됩니다. 링크는 누를 때마다 새 토큰을 만듭니다(토큰을 메뉴 HTML에 미리 넣지 마세요).

## 4. 비밀값 바꾸기 (교체 절차)
비밀값이 새었거나 정기 교체할 때. 몇 분 동안만 입장이 안 될 수 있으니 수업이 없는 시간에 합니다.
1. `openssl rand -hex 32`로 새 값을 만듭니다.
2. 읽기 시선 기록 서버: `.env`의 `SSO_SECRET`을 새 값으로 바꾸고 `docker compose up -d` (재시작).
3. 다힘 사이트: `DAHIM_READING_SECRET`(또는 비밀값 파일)을 같은 값으로 바꿉니다(php-fpm을 쓰면 재시작).
4. 아래 5번으로 확인합니다. 이미 들어와 있던 사람의 로그인(최대 12시간)은 그대로 유지됩니다. 즉시 끊어야 하면 읽기 서버의 관리자 화면에서 해당 계정을 비활성화합니다.
- 2와 3 사이에 들어오는 사람은 "다힘 사이트에서 다시 들어와 주세요"를 봅니다. 3이 끝나면 다시 누르면 됩니다.

## 5. 확인할 것
- 원장 계정으로 "읽기 시선 기록" → 아이 목록이 열리고 모든 선생님의 아이가 보이면 정상.
- 선생님 계정으로 → 자기 아이만 보이면 정상. 학생 화면의 "측정" → 그 학생 또는 등록 칸이 보이면 정상. 다른 반 학생 번호로 시험하면 "맡은 반 학생만 측정할 수 있어요."가 나와야 정상.
- 학생 계정으로 "읽기 측정" → 등록된 학생이면 측정 화면, 아니면 "아직 측정 대상으로 등록되지 않았어요. 선생님께 말씀해 주세요."
- 주소창의 `/sso?t=...` 주소를 복사해 다시 열면 "다힘 사이트에서 다시 들어와 주세요"가 나와야 정상(한 번만 쓰임). 5분 지나도 마찬가지.
- "다힘 사이트에서 다시 들어와 주세요"만 계속 나오면: 두 서버의 비밀값이 다른지, 두 서버 시계가 1분 이상 어긋났는지(`date -u` 비교) 확인합니다.
- "읽기 시선 기록 연결이 아직 설정되지 않았어요"가 나오면: 다힘 쪽 비밀값이 없거나 32자보다 짧습니다.

## 6. 직접 검증한 것과 못 한 것
- 토큰 함수는 php:8.3-cli 도커에서 문법 검사와 시험(`tests/php/decide-test.php`)을 통과했고, PHP가 만든 토큰을 Node 서버가 검증하는 시험(`tests/sso-php.test.js`)이 있습니다.
- 다힘 세션 변수 이름(`admin_logged_in`, `admin_teacher_id`, `student_logged_in`, `student_id`)과 `drs_scope()`/`drs_ok()` 사용법은 다힘 코드를 **읽어서** 확인했습니다. 실제 다힘 서버에서 실행해 보지는 않았으니, 설치 뒤 5번 확인을 꼭 해 주세요.
