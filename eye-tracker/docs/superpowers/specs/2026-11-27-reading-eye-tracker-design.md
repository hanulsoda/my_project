# 아동 읽기 시선 추적 시스템 — 설계

## 의도와 이유
센터/학교 선생님이 아이들의 읽기 능력을 시선 이동으로 측정한다. 읽기 속도, 읽기 정확성, 눈이 머물거나 넘어가지 못하는 지점을 찾아 부모 상담과 읽기 지도에 쓴다. 한 번의 측정이 아니라 **아이별 기록을 누적**해 시간에 따른 향상을 수시로 본다.

## 사용자와 사용 방식
- 선생님 한 명 또는 소수가 여러 아이를 관리한다 (로그인 필요).
- 부모는 계정이 없다. 상담 때 리포트(공유 링크 또는 PDF)만 받는다.
- 아이는 태블릿(거치대 고정) 또는 노트북의 내장 카메라 앞에서, 프로그램이 제시하는 지문을 읽는다.

## 목표
- 줄 단위 추적 안정, 단어 단위 분석은 큰 글자·넓은 줄 간격 지문에서 가능한 수준.
- 지표: 읽기 속도(분당 단어), 되돌아 읽기 횟수, 줄 건너뜀, 단어별 머문 시간.
- 아이별 시계열 누적과 비교, 부모용 한 장 리포트.
- 아이가 지루하지 않은 보정(공 따라가기 약 10초).

## 비목표
- 난독증 등 진단 도구가 아니다. 상담용 선별 지표로만 표시한다.
- 아이가 평소 쓰는 외부 전자책/앱 위에서의 추적(글 위치를 알 수 없음).
- 네이티브 앱, 전용 시선 추적 하드웨어.
- 부모 로그인/부모 계정.

## 안티 목표 (이렇게 되면 기술적으로 동작해도 실패)
- 아이 얼굴 영상이 기기 밖으로 나가거나 저장되는 것.
- 보호자 동의 없이 아이 데이터가 서버에 쌓이는 것.
- 오차가 큰 결과를 확정적 판단처럼 보여 주는 것.

## 제약
- 14세 미만 아동 정보: 동의, 접근 통제, 삭제 처리 필수.
- 카메라는 https 또는 localhost에서만 허용 → 서버는 https 필요.
- 일반 카메라 약 30fps: 머무름 시간은 근사값.
- 서버는 Oracle Cloud VM. 이 설계 단계에서는 VM 접속 정보가 없다.

## 접근 방식 (검토한 것)
- A. 브라우저 단독, 기기 내 저장: 개인정보 부담 최소. 누적/다기기 비교 불가 → 목적(누적 측정)에 맞지 않아 탈락.
- **B. 브라우저 + Oracle 서버 저장: 선택됨.** 촬영·시선 계산은 기기 안, 서버에는 시선 좌표·지표만 전송.
- C. 태블릿 전용 앱: 노트북 미지원, 기종별 개발 → 탈락.

## 사용자가 정한 것
- 읽을 글은 프로그램 안 지문 (단어별 화면 위치를 알 수 있음).
- 방식은 B, 선생님 계정 + 부모는 리포트만.

## 사용자가 추가로 정한 것 (검토 후)
- 보호자 동의: 처음에 종이로 받는다. 선생님이 앱에 "동의 받음"과 날짜를 기록하고, 기록이 없는 아이는 측정을 시작할 수 없다.
- 대상: 초등~고등학생, 한국어 지문. 학년에 따라 글자 크기·지문 길이·보정 시간을 달리한다.
- 도메인: dahim.kr (서비스 주소는 하위 도메인, 예: reading.dahim.kr — 빌더 판단).

## 제안(빌더 판단, 사용자 확정 아님)
- 앱·API·DB를 한 묶음(컨테이너)으로 구성해 VM에서 한 번에 기동.
- 지문 구분: 매번 같은 난이도의 **기준 지문**(추이 비교용)과 **새 지문**.
- 시선 엔진은 브라우저 내 웹캠 방식(현재 WebGazer 기반 프로토타입 `app/`)으로 시작하고, 실제 아이·기기에서의 오차를 측정해 교체 여부를 판단.
- 리포트는 공유 링크(만료·취소 가능)와 인쇄/PDF.

## 빌더에게 맡기는 것
- 기술 스택, DB 스키마, 지표 계산 알고리즘(고정 응시 판정, 줄 인식), 화면 세부 디자인, 지문 초기 세트와 한국어 난이도 기준.
- 테스트 전략(카메라 없는 환경에서는 녹화된 시선 데이터로 지표 계산을 검증).

## 검토 후 추가한 판단 (빌더 판단, 사용자 확정 아님)
- 정확도: 구현 첫 단계에 실제 아이·기기로 오차를 재는 측정 단계를 둔다. 세션마다 품질 점수를 계산해, 기준 미달 세션은 "참고용"으로 표시하고 단어 단위 결과를 숨기며 줄 단위만 보여 준다. 진단처럼 보이는 문구는 쓰지 않는다.
- 비교: 아이 본인의 과거 기록과만 비교한다. 학년 평균 같은 규준 비교는 이번 범위에서 제외.
- 계정: 하나의 기관 단위. 관리자가 선생님을 초대하고, 선생님은 자신이 맡은 아이만 본다. 비밀번호 재설정 포함.
- 리포트: 실명 대신 이름 이니셜/코드를 표시. 공유 링크는 기본 30일 후 만료, 선생님이 언제든 폐기 가능. PDF도 같은 내용.
- 저장 데이터: 파생 지표와 시선 좌표(재분석용)를 저장. 얼굴 영상은 저장·전송하지 않는다. 삭제 요청 시 해당 아이의 모든 기록을 영구 삭제.
- 기기: iPad Safari, Android Chrome, 노트북 Chrome/Edge. 규모는 센터 한 곳 수준(수십~수백 명)으로 보고 VM 한 대로 시작.
- 14세 이상(중·고등) 학생도 같은 방식(보호자 종이 동의)으로 통일해 단순화한다.
- https 인증서는 Let's Encrypt로 자동 발급. VM 접속 정보가 없으므로 산출물은 `docker compose up` 한 번으로 기동되는 묶음과 배포 안내서까지로 하고, 실제 서버 반영은 접속 권한이 주어질 때 진행한다.
